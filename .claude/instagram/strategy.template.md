# 인스타그램 운영 전략

사용자가 정한 운영 방식. 모든 ig-* 스킬과 릴스 제작 작업은 이 파일을 먼저 읽는다.
설치할 때 AI가 사용자와 인터뷰해서 `[ ]` 칸을 채우고 `strategy.md`로 저장한다.
"(기본값)" 줄은 이 키트를 만든 사람이 써보고 정한 것이다. 사용자가 다르게 원하면 바꾼다.

## 운영 루프 (기본값)

1. 분야 릴스 중 조회수 100만 이상, 또는 팔로워 수의 10배 이상인 것을 저장한다.
2. 편집이 마음에 드는 릴스 3~6개를 화면 녹화해서 `/reels-style`로 `style.yaml`을 만든다.
3. 저장한 릴스의 후킹과 주제로 대본 약 30개를 쓴다 (`/ig-reel`).
4. 첫 바이럴까지 매일 올린다. 평소 조회수의 3배 이상이면 바이럴로 본다.
5. 터진 영상은 후킹과 주제를 그대로 두고 포맷만 바꿔 다시 올린다.
6. 올린 릴스와 성과는 `log.md`에 적는다.

레퍼런스에서는 후킹 구조와 주제만 가져온다. 원본 대본, 영상, 편집을 그대로 쓰지 않는다.

## 촬영과 전달 (기본값)

- 전달: 구글 드라이브에 "릴스 원본" 폴더를 만들고 "링크가 있는 모든 사용자"로 공유한다.
  사용자는 영상을 올리고 "올렸어"라고만 말한다. AI가 드라이브 커넥터로 새 파일을 찾아 내려받는다.
- 드라이브 폴더 ID: [ ]
- 아이폰 설정: 설정 > 카메라 > 포맷 "고효율", 비디오 녹화 1080p 30fps, HDR 비디오 끔.
  (HDR로 찍어도 자동 변환되지만 색이 뜨고 느려진다.)
- 세로로 찍는다. 위에 그래픽이 올라가므로 몸과 동작은 화면 가운데 절반 안에 둔다.
- 대본 하나는 한 번에 쭉 찍는다. 틀리면 멈추지 않고 2초 쉰 뒤 그 문장 처음부터 다시 말한다.
  편집은 마지막으로 끝까지 말한 테이크를 쓴다.
- 말 없는 구간은 자동으로 잘린다. 말없이 보여줄 장면은 3~5초만 찍는다.
- 해부학 설명이 필요하면 해부학 앱을 화면 녹화해서 같은 폴더에 올린다. 근육 하나당 5~10초,
  천천히 돌리고 확대한 뒤 2초 멈춘다. 녹화 목록은 `anatomy.md`에 적는다.

## 편집 방향 (기본값)

- 정보형: 얼굴 전체 / 위 그래픽 아래 얼굴 / 그래픽 전체가 2~5초마다 바뀐다 (`layout: mixed`).
  웃긴형: 전체 화면 영상 + 자막만 (`layout: full`).
- 그래픽은 글을 다시 쓰지 않고 말에 나오는 대상을 보여준다. 앱을 말하면 앱 화면 디자인, 시간을
  말하면 시계, 논문을 말하면 논문 카드. 말과 그래픽이 맞는 게 전문성이다.
- 어두운 톤. 실제 로고나 사진이 없어도 디자인으로 만든다.
- 말과 맞으면 얼굴 화면을 흑백이나 작은 카드로 줄여도 된다.
- 자막은 전부 넣는다.
- 효과음은 담백하게. 배경음악은 사용자가 인스타에서 직접 고른다.
- 화면 속 숫자, 시각, 논문 정보는 실제 값만 쓴다.
- 자세 방향이 중요한 설명(골반 기울기, 근육이 당기는 방향)은 AI 영상을 쓰지 않는다. 해부학 앱
  녹화 위에 선·화살표·원·이름표를 그린다. AI 영상은 방향을 두 번 다 틀렸다.
